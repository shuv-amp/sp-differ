# Semantic Worker Corpus

This corpus stores deterministic UTF-8 JSON requests and malformed raw payloads for the semantic worker ABI.

- `valid/` contains canonical semantic adapter requests derived from the vendored official v2 corpus and any promoted semantic regression requests.
- `invalid/` contains malformed or contract-breaking raw payloads used to verify clean rejection behavior.
- `manifest.json` is generated by `python3 scripts/generate_semantic_fuzz_corpus.py`.

The checked-in corpus is not hand-edited. Regenerate it with:

```bash
python3 scripts/generate_semantic_fuzz_corpus.py
```
